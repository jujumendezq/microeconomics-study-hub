# 📘 Microeconomics Study Hub

A comprehensive study resource for Introduction to Microeconomics.

## 📚 What's Included

- **12 Lessons** - Complete course notes from methodology to uncertainty
- **6 Seminars** - Interactive seminar exercises with solutions
- **6 Problem Sets** - Practice problems with answer keys (PDF)
- **Seminar PDFs** - Detailed seminar slides (PDF)
- **7 Past Exams** - Practice exams with corrections (August 2023-2025, January 2023-2025 + Question Bank)
- **Glossary** - Complete list of microeconomics terms
- **Quizzes** - Self-assessment quizzes

## 🚀 How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Navigate using the sidebar
